CSS xususiyatlari

CSS veb-sahifalarning ko'rinishini o'zgartirish uchun ishlatiladi. Color matn rangini belgilaydi. Background-color fon rangini belgilaydi. Border element chegarasini belgilaydi. Width element kengligini, height esa balandligini belgilaydi. Overflow: scroll element ichidagi kontentni aylantirib ko'rish imkonini beradi.

Bu div elementi. Uning foni yashil, matni oq rangda. Element chegarasi to'q yashil rangda. Kengligi 350px, balandligi 150px. Ichidagi matn ko'payib ketsa, scroll orqali qolgan matnni ko'rish mumkin. HTML sahifa tuzish uchun ishlatiladi. CSS esa sahifaga rang va o'lcham beradi. Bu yerda faqat o'rganilayotgan CSS xususiyatlaridan foydalanilgan.
