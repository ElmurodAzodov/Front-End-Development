Frontend Dasturlash

Frontend dasturlash — web saytlarning foydalanuvchi ko‘radigan qismini yaratish sohasi.

Frontend dasturchi HTML, CSS va JavaScript texnologiyalaridan foydalanadi.

HTML nima?

HTML — HyperText Markup Language so‘zlarining qisqartmasi. HTML web sahifaning tuzilmasini yaratish uchun ishlatiladi.

HTML dasturlash tili emas, balki belgilash tili.

HTML yordamida nimalar yaratish mumkin?

  • Sarlavhalar
  • Matnlar
  • Havolalar
  • Ro‘yxatlar
  • Formalar
  • Jadvallar
  • Web sahifa tuzilmasi

CSS nima?

CSS — Cascading Style Sheets so‘zlarining qisqartmasi.

CSS yordamida HTML elementlariga rang, o‘lcham, joylashuv va boshqa dizaynlar beriladi.

HTML — tuzilma.
CSS — dizayn.
JavaScript — interaktivlik.

JavaScript

JavaScript web sahifaga interaktivlik va harakat qo‘shish uchun ishlatiladi.

Masalan, tugma bosilganda biror amal bajarilishi, modal oynaning ochilishi yoki ma'lumotlarning serverdan olinishi JavaScript yordamida amalga oshirilishi mumkin.
