LocalStorage

Bu sahifa JavaScript localStorage mavzusini o'rganish uchun yaratilgan. Quyidagi ma'lumotlar brauzeringizda saqlanadi.

Nimalarni o'rganasiz?

✅ localStorage.setItem() - ma'lumot saqlash
✅ localStorage.getItem() - ma'lumot o'qish
✅ localStorage.removeItem() - ma'lumot o'chirish
✅ JSON.stringify() va JSON.parse()
✅ Foydalanuvchi autentifikatsiyasi
